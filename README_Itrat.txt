عِترة الإسلام — حزمة الويب الجاهزة للرفع

المحتويات:
- index.html: التطبيق
- manifest.json: بيانات تثبيت PWA
- service-worker.js: تخزين واجهة التطبيق الأساسية
- itrat-icon-192.png و itrat-icon-512.png و itrat-icon.svg: الأيقونات
- .github/workflows/pages.yml: نشر GitHub Pages تلقائيًا عند رفع الملفات على main

رفع الحزمة من الموبايل:
1) افتح github.com وسجل دخولك/أنشئ حسابًا بمساعدة ولي أمرك عند الحاجة.
2) أنشئ repository باسم itrat-islam. اختر Public.
3) فك ضغط هذا الملف ZIP على جهازك.
4) ارفع كل محتويات المجلد إلى جذر المستودع (لا ترفع ZIP نفسه فقط). احتفظ بمجلد .github.
5) Settings > Pages، واختَر GitHub Actions للنشر.
6) انتظر نجاح Actions ثم افتح رابط Pages. اختبر التطبيق على هاتف حقيقي.

تنبيه:
هذه حزمة PWA وليست APK أو AAB. البيانات والتلاوات والخدمات الخارجية تتطلب الإنترنت.
التذكيرات داخل الصفحة ليست تنبيهات Android مضمونة عندما يكون التطبيق مغلقًا.
لم يتم اختبار كل القراء أو الموقع أو التنبيهات على جهاز حقيقي في هذا الفحص.
